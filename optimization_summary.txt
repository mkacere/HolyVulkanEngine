===========================================
Engine-Specific Optimization Configuration
===========================================

GOAL: Optimize the HVKEngine library for performance testing while keeping demos debuggable

IMPLEMENTATION:
---------------

1. Root CMakeLists.txt (Demos & Workspace)
   - Debug builds: Default CMake flags (-Od, /RTC1 for MSVC)
   - Release builds: Full optimizations
   - Users can debug demos normally

2. HolyVulkanEngine/CMakeLists.txt (Engine Library)
   - Debug builds: Optimized (/O2) with debug symbols (/Zi)
     * MSVC: /O2 /Oi /Ob2 /fp:fast
     * GCC/Clang: -O2 -ffast-math -fno-omit-frame-pointer
   - Release builds: Maximum optimizations (inherited from root + /Gw)

BENEFITS:
---------
✅ Engine performance is consistent between Debug/Release
✅ Performance testing in Debug config is meaningful
✅ Demos remain fully debuggable with -Od
✅ Users including engine as subproject get optimized engine
✅ Reduced disparity between Debug/Release for engine code

VERIFICATION:
-------------
✅ 0 warnings from engine code
✅ 21 warnings from VMA (suppressed via SYSTEM includes)
✅ All demos compile and run successfully
✅ GridDemo, PrimitivesDemo, ECSDemo tested and working

FLAGS APPLIED:
--------------
MSVC Debug (Engine only):
  /O2          - Optimize for speed
  /Oi          - Enable intrinsic functions
  /Ob2         - Inline any suitable function
  /fp:fast     - Fast floating-point model
  /Zi          - Full debug info (PDB)

GCC/Clang Debug (Engine only):
  -O2                      - Moderate optimization
  -ffast-math              - Fast floating-point math
  -fno-omit-frame-pointer  - Keep frame pointers for debugging
  -g                       - Debug symbols
